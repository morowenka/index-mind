# ХУЙ

- если в уже проиндексированном файле произошли какие-то изменения (удаление/добавление/переписание какой-либо информации), изменения надо подтянуть, нажав на "Обновить индексы". Система сама определит что надо добавить в индексы и что надо убрать, если были зафиксированы изменения.

- существующие файлы проиндексированы заново не будут, даже если их добавлять и обновлять

- разные адаптеры для индексации разных форматов документов
